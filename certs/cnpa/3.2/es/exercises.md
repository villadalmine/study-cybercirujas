# 3.2 Continuous Delivery Concepts and GitOps Principles

## Motivación y Principios de GitOps

**GitOps** utiliza Git como la **única fuente de verdad** para reconciliar el estado deseado en Kubernetes de forma declarativa y automatizada.

---

## 1. Principios de OpenGitOps

- Declarativo.
- Versionado e Inmutable.
- PULL Automatizado.
- Reconciliación Continua.
