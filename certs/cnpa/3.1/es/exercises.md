# 3.1 Continuous Integration Fundamentals and Best Practices

## Motivación y Prácticas de CI

**Continuous Integration (CI)** automatiza la compilación, pruebas unitarias y linters en cada commit para detectar fallos tempranos en el desarrollo de aplicaciones cloud native.

---

## 1. Pilares de CI

- Pruebas automatizadas en cada Pull Request.
- Construcción reproducible de imágenes de contenedor.
- Análisis estático de código (SAST) y linting de manifiestos.
