# Exercises: Essential System Services (Topic 2.4)

## Exercise 1: Querying System Logs with `journalctl`

As an SRE, you frequently need to investigate service failures using the systemd journal, which aggregates logs across the entire system.

1. View the logs for a specific systemd unit (e.g., `ssh.service` or `sshd.service`):
   ```bash
   journalctl -u ssh.service
   ```
2. Limit the output to logs generated since the last system boot, and only show errors (`err`) or worse:
   ```bash
   journalctl -b -p err
   ```
3. Follow the logs in real-time (like `tail -f`):
   ```bash
   journalctl -f
   ```

**Question 1.1:** What flag would you add to `journalctl` to display the logs in reverse chronological order (newest first)?
**Question 1.2:** By default, where does `systemd-journald` store its logs persistently on disk if configured to do so?

## Exercise 2: Checking Time Synchronization with `chrony`

Accurate time is essential for TLS, databases, and log correlation.

1. Check if the system clock is synchronized:
   ```bash
   timedatectl status
   ```
2. View the current NTP sources that `chrony` is polling:
   ```bash
   chronyc sources -v
   ```
3. View the tracking statistics (drift, offset, stratum):
   ```bash
   chronyc tracking
   ```

**Question 2.1:** In the output of `chronyc sources`, what does an asterisk (`*`) next to the source name indicate?
**Question 2.2:** What is a "Stratum 1" time server?

## Exercise 3: Inspecting the MTA Queue

Even if you aren't running a full email server, your local Mail Transfer Agent (MTA) might be queuing alerts from cron jobs or daemons.

1. List the current mail queue:
   ```bash
   mailq
   ```
2. If using Postfix, you can force the MTA to attempt to flush (deliver) the queue immediately:
   ```bash
   sudo postqueue -f
   ```

**Question 3.1:** What command allows you to create aliases (e.g., mapping the `root` user's email to an external admin address) and which file does it process?
**Question 3.2:** If `mailq` outputs `Mail queue is empty`, what does this signify?
