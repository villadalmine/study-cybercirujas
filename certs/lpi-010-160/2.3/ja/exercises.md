## 演習 1: 現在地を確認する — `pwd`

1. ターミナルを開きます。ログイン直後は通常 home directory（`/home/<username>`）にいます。
2. `pwd`（print working directory）コマンドを実行し、現在の絶対パス（absolute path）を確認します。

```bash
pwd
```

3. 出力された結果をメモしておきます。以降の演習でこのパスと比較します。

**確認問題**
- `pwd` は何の略で、何を表示しますか。
- ログイン直後にいるディレクトリを英語で何と呼びますか。

---

## 演習 2: ディレクトリの中身を見る — `ls`

1. 現在のディレクトリの中身を一覧表示します。

```bash
ls
```

2. 詳細情報（パーミッション、所有者、サイズ、更新日時など）を含む long format で表示します。

```bash
ls -l
```

3. `.`（ドット）で始まる隠しファイル（hidden files）も含めて表示します。

```bash
ls -a
```

4. ファイルとディレクトリを区別しやすくするため、種類を示す記号を付けて表示します（ディレクトリには `/`、実行可能ファイルには `*` など）。

```bash
ls -F
```

**確認問題**
- Linuxで「隠しファイル」とみなされるのはどのようなファイル名ですか。
- `ls -l` の出力で、行の先頭が `d` になっている場合、それは何を意味しますか。
- `ls -F` でディレクトリ名の末尾に付く記号は何ですか。

## 演習 3: 絶対パスと相対パス — absolute path と relative path

1. 自分の home directory の中に `practice` というディレクトリを作成します。

```bash
mkdir practice
```

2. `practice` に移動します（相対パス、relative path での指定）。

```bash
cd practice
pwd
```

3. home directory に戻り、今度は絶対パス（absolute path、`/` から始まる完全なパス）で `practice` に移動します。

```bash
cd ~
cd ~/practice
pwd
```

4. 一つ上の階層（親ディレクトリ、parent directory）に移動します。

```bash
cd ..
pwd
```

5. 直前にいたディレクトリに戻ります。

```bash
cd -
pwd
```

**確認問題**
- `~`、`.`、`..`、`-` はそれぞれ `cd` コマンドと組み合わせたとき何を意味しますか。
- 絶対パスと相対パスの違いを説明してください。

## 演習 4: ディレクトリの作成 — `mkdir`

1. `practice` ディレクトリの中に、複数階層のディレクトリ構造を一度に作りたいとします。まず、親ディレクトリを作らずに直接試してみます。

```bash
cd ~/practice
mkdir projects/2024/report
```

2. エラーメッセージが表示されることを確認します（親ディレクトリ `projects` と `projects/2024` が存在しないため）。
3. `-p`（parents）オプションを使って、必要な親ディレクトリも含めて一度に作成します。

```bash
mkdir -p projects/2024/report
```

4. `ls -R`（recursive）で作成された階層構造をまとめて確認します。

```bash
ls -R projects
```

**確認問題**
- `mkdir` に `-p` オプションを付けない場合、なぜ手順1のコマンドは失敗しますか。
- `ls -R` はどのような場面で役立ちますか。

## 演習 5: ファイルの種類を調べる — `file`

1. `practice` ディレクトリの中にテキストファイルを一つ作成します。

```bash
cd ~/practice
echo "Hello LPI" > notes.txt
```

2. `file` コマンドでファイルの種類（file type）を確認します。

```bash
file notes.txt
```

3. ディレクトリに対しても `file` を実行し、出力の違いを観察します。

```bash
file projects
```

**確認問題**
- `file` コマンドはファイルの種類をどのように判定していますか（拡張子だけを見ているわけではない点に注目）。
- `file` をディレクトリに対して実行すると、どのような結果になりますか。

## 演習 6: ディレクトリの削除 — `rmdir` と `rm -r`

1. 中身が空のディレクトリを作成し、`rmdir` で削除します。

```bash
mkdir empty_dir
rmdir empty_dir
```

2. 中身のあるディレクトリ（例: `projects`）に対して `rmdir` を試し、結果を観察します。

```bash
rmdir projects
```

3. エラーになることを確認したら、`rm` に `-r`（recursive）オプションを付けて、中身ごと削除します。

```bash
rm -r projects
```

**確認問題**
- `rmdir` が中身のあるディレクトリに対して失敗するのはなぜですか。
- `rmdir` と `rm -r` の使い分けの基準を説明してください。

## 演習 7: ファイルを探す — `find`

1. `practice` ディレクトリの中に、拡張子違いのファイルをいくつか作成します。

```bash
cd ~/practice
touch report1.txt report2.txt image1.png
```

2. カレントディレクトリ以下から、名前が `report` で始まるファイルを探します。

```bash
find . -name "report*"
```

3. 種類を指定して、ディレクトリのみを検索します。

```bash
find . -type d
```

4. 種類を指定して、通常ファイル（regular file）のみを検索します。

```bash
find . -type f
```

**確認問題**
- `find . -name "report*"` の `.` は何を表していますか。
- `-type d` と `-type f` はそれぞれ何を絞り込む条件ですか。
- `ls` と `find` の主な違いは何ですか（検索範囲や再帰性の観点で）。

## 演習 8: 総合演習

1. home directory に `lab` というディレクトリを作り、その中に `docs` と `.config`（隠しディレクトリ）という2つのサブディレクトリを一度に作成します。

```bash
cd ~
mkdir -p lab/docs lab/.config
```

2. `lab` ディレクトリに移動し、隠しファイル・ディレクトリも含めて詳細一覧を表示します。

```bash
cd lab
ls -la
```

3. `docs` の中に `readme.txt` を作成し、`find` コマンドで `lab` 以下の全ファイル（ディレクトリを除く）を探します。

```bash
touch docs/readme.txt
find ~/lab -type f
```

**確認問題**
- `.config` のようなディレクトリが `ls`（オプションなし）の出力に表示されない理由は何ですか。
- `ls -la` の `l` と `a` はそれぞれ何を意味しますか。

**演習1**
- `pwd` は "print working directory" の略で、現在いるディレクトリの絶対パスを表示する。
- home directory（ホームディレクトリ）。

**演習2**
- ファイル名の先頭が `.`（ドット）で始まるファイルやディレクトリが隠しファイルとみなされる。
- `d` はそのエントリが directory（ディレクトリ）であることを示す（通常ファイルは `-`）。
- `/`(スラッシュ)。

**演習3**
- `~` は自分の home directory、`.` はカレントディレクトリ（自分自身）、`..` は一つ上の親ディレクトリ、`-` は直前にいたディレクトリを表す。
- 絶対パスは `/` から始まり、ファイルシステムのルートからの完全な経路を示す。相対パスは現在のディレクトリを基準にした経路であり、`.` や `..` を使って表現することが多い。

**演習4**
- `projects` も `projects/2024` もまだ存在しないため、`mkdir` は指定された最後の階層だけを作ろうとして失敗する。`-p` を付けると、存在しない親ディレクトリも自動的にまとめて作成される。
- ディレクトリ階層全体を一度に俯瞰したいとき、特に深い階層構造の確認に役立つ。

**演習5**
- `file` はファイルの内容（マジックナンバーなど）を解析して種類を判定するため、拡張子が間違っていたり存在しなくても正しい種類を推測できる。
- そのパスが directory であることを示す結果（例: `projects: directory`）が返る。

**演習6**
- `rmdir` は空のディレクトリしか削除できないという安全対策のための仕様であり、中身がある場合は失敗する。
- 空のディレクトリだけを安全に削除したい場合は `rmdir`、中身ごと一括で削除したい場合は `rm -r` を使う。`rm -r` は誤操作で大量のファイルを失う危険があるため注意が必要。

**演習7**
- `.` はカレントディレクトリを起点として検索することを表す。
- `-type d` はディレクトリのみを、`-type f` は通常ファイルのみを検索対象として絞り込む条件。
- `ls` は指定したディレクトリの直下の内容を一覧表示するのが基本（`-R` を付けない限り再帰しない）のに対し、`find` は指定した起点以下のディレクトリツリー全体を再帰的に探索し、名前や種類などの条件で絞り込める。

**演習8**
- `ls`（オプションなし）はデフォルトで隠しファイル・隠しディレクトリを表示しないため、`.` で始まる `.config` は一覧に出てこない。
- `-l` は long format（詳細情報付き）での表示、`-a` は隠しファイル・ディレクトリを含めたすべてのエントリの表示を意味する。
