# LPI Linux Essentials (010-160, v1.6) — トピック 2.2: Using the Command Line to Get Help

> 出典（参照のみ、引用ではなくオリジナル解説）: https://learning.lpi.org/en/learning-materials/010-160/2/2.2/

Linux のコマンドは数百〜数千あり、すべてのオプションを暗記するのは非現実的です。このトピックでは、ターミナルを離れずに **man**、**--help**、**info**、`/usr/share/doc` を使って必要な情報を調べる方法を練習します。

---

## 演習1: `--help` オプションで素早く確認する

多くの GNU コマンドは `--help` オプションに対応しており、使用可能な引数の一覧を短く出力してくれます。

1. ターミナルを開き、`ls` コマンドの `--help` を実行します。
   ```bash
   ls --help
   ```
2. 出力の中から `-l` オプションの説明を探します。
3. 同様に `cp --help` と `date --help` を実行し、それぞれの出力の長さやフォーマットを比べます。
4. 出力が長すぎてターミナルからあふれる場合、`less` にパイプして読みやすくします。
   ```bash
   ls --help | less
   ```

**確認問題**
1. `--help` の出力と `man` ページの出力では、情報の詳しさにどのような違いがありますか？
2. `--help` オプションに対応していないコマンド（例: 古い Unix 由来のコマンド）に遭遇した場合、次にどの手段を試すべきですか？

## 演習2: `man` コマンドでマニュアルページを読む

`man`（manual の略）は Linux の標準的なオンラインマニュアルシステムです。

1. `ls` コマンドのマニュアルページを開きます。
   ```bash
   man ls
   ```
2. `man` は内部で `less` を使ってページャー表示します。以下のキー操作を試してください。
   - `Space` または `f`: 次のページへ
   - `b`: 前のページへ
   - `/pattern`: 下方向に文字列 `pattern` を検索
   - `n`: 次の検索結果へ
   - `q`: `man` を終了
3. `man` ページの構成セクション（`NAME`、`SYNOPSIS`、`DESCRIPTION`、`OPTIONS`、`EXAMPLES`、`SEE ALSO` など）をそれぞれ確認します。
4. `man man` を実行し、`man` コマンド自体のマニュアルページを開いてみます。

**確認問題**
1. `man` ページ内で `-l` オプションの説明を探すには、`man ls` を開いた後に何を入力しますか？
2. `SYNOPSIS` セクションに書かれている `[ ]`（角括弧）はコマンドの構文において何を意味しますか？

---

## 演習3: man ページのセクション番号を理解する

`man` ページは番号付きのセクションに分類されています（例: 1 = ユーザーコマンド、5 = 設定ファイル、8 = システム管理コマンドなど）。同じ名前がコマンドにもファイルにも存在する場合があります。

1. `passwd` という単語で man ページがいくつ存在するか確認します。
   ```bash
   man -f passwd
   ```
   （`whatis passwd` でも同じ結果が得られます）
2. 出力に表示された複数のセクション番号を確認します。
3. セクション 1（コマンド）の `passwd` ページを明示的に開きます。
   ```bash
   man 1 passwd
   ```
4. セクション 5（ファイル形式）の `passwd` ページを開き、`/etc/passwd` ファイルのフォーマット説明を確認します。
   ```bash
   man 5 passwd
   ```

**確認問題**
1. `passwd` のマニュアルページがセクション 1 とセクション 5 の両方に存在するのはなぜですか？
2. セクション番号を指定せずに `man passwd` とだけ実行すると、どちらのページが表示されますか？

## 演習4: `apropos` と `whatis` でコマンドを検索する

コマンド名の一部しか覚えていない場合や、目的から逆にコマンドを探したい場合に使います。

1. `whatis` で完全一致検索を行い、コマンドの1行説明を取得します。
   ```bash
   whatis grep
   ```
2. `apropos` を使い、キーワードに関連するすべてのコマンドを検索します（man ページの `NAME` セクションを全文検索します）。
   ```bash
   apropos "copy files"
   ```
3. 同じ検索を `man -k` でも実行し、結果が `apropos` と同じであることを確認します。
   ```bash
   man -k "copy files"
   ```
4. `apropos` の検索対象データベースが最新でない場合、`sudo mandb` でデータベースを更新できることを覚えておきます（実行は任意）。

**確認問題**
1. `whatis` と `apropos` の検索範囲の違いは何ですか？
2. `apropos` の検索結果が空、または古い場合に疑うべき原因は何ですか？

---

## 演習5: `info` コマンドで詳細なドキュメントを読む

GNU プロジェクトのコマンドの中には、`man` ページより詳しい **info** 形式のドキュメントを持つものがあります。info はハイパーリンクのようにノード間を移動できるのが特徴です。

1. `ls` の info ドキュメントを開きます。
   ```bash
   info ls
   ```
2. 以下のキー操作でノード間を移動します。
   - `n`: 次のノードへ
   - `p`: 前のノードへ
   - `u`: 上位のノードへ
   - `Enter`（リンク上にカーソルがある状態）: リンク先のノードへジャンプ
   - `q`: 終了
3. `info coreutils 'ls invocation'` のように、特定のトピックを直接指定して開く方法も試します。

**確認問題**
1. `man` と `info` のどちらが、ノード間をリンクでたどれる構造になっていますか？
2. GNU コマンドで `man` ページの内容が簡略化されており、詳細が `info` にしかない場合があります。この状況で最初に確認すべきセクションは `man` ページのどこですか？

## 演習6: `/usr/share/doc` 以下の追加ドキュメントを探す

パッケージによっては、man や info とは別に `/usr/share/doc/` 以下に README、CHANGELOG、サンプル設定ファイルなどを提供しています。

1. `bash` パッケージに関連するドキュメントディレクトリを一覧表示します。
   ```bash
   ls /usr/share/doc/bash*
   ```
   （ディストリビューションによってディレクトリ名の末尾にバージョン番号が付く場合があります）
2. 中身にテキストファイルがあれば `less` で開いて確認します。
   ```bash
   less /usr/share/doc/bash*/README
   ```
3. 圧縮された `changelog.gz` のようなファイルがある場合、展開せずに直接内容を確認します。
   ```bash
   zless /usr/share/doc/bash*/changelog.Debian.gz
   ```

**確認問題**
1. `/usr/share/doc` に置かれる情報は、`man` ページに書かれる情報とどのように性質が異なりますか？
2. 拡張子が `.gz` のドキュメントファイルを、展開せずに読むためのコマンドは何ですか？

**演習1**
1. `--help` はオプション一覧を簡潔に表示するだけですが、`man` ページは `DESCRIPTION`、`EXAMPLES`、`SEE ALSO` などを含み、より詳細な説明を提供します。
2. `man <コマンド名>` を試します。それでも見つからない場合は `info <コマンド名>` や `apropos` での検索を試みます。

**演習2**
1. `/` に続けてキーワード（例: `/-l`）を入力し `Enter` を押します。`n` キーで次の一致箇所へ移動できます。
2. 角括弧 `[ ]` は「省略可能」であることを示します。角括弧のない引数は必須です。

**演習3**
1. `passwd` という名前が、ユーザーが実行する**コマンド**（セクション1）と、システムが読み込む**設定ファイルのフォーマット**（セクション5）の両方を指すため、それぞれ別のドキュメントとして用意されています。
2. `man` は原則としてセクション番号を昇順に検索し、最初に見つかったページ（通常はセクション1）を表示します。

**演習4**
1. `whatis` はコマンド名の完全一致のみを検索しますが、`apropos` は man ページの `NAME` 説明文をキーワードで全文検索するため、コマンド名を正確に覚えていなくても該当ページを見つけられます。
2. man ページのインデックスデータベース（`mandb` が管理するデータベース）が更新されていないことが原因である可能性が高く、`sudo mandb` で再構築できます。

**演習5**
1. `info` です。ノード間をハイパーリンクのようにたどれる構造（Texinfo 形式）を持っています。
2. `SEE ALSO` セクションを確認します。多くの GNU コマンドの man ページはここで「詳細は info ページを参照」と案内しています。

**演習6**
1. `man` ページはコマンドの使い方（オプションや構文）を説明するリファレンスですが、`/usr/share/doc` にはインストールの背景、変更履歴、ライセンス情報、設定例など、より補足的な文書が置かれることが多いです。
2. `zless`（または `zcat` をパイプで `less` に渡す方法）です。
