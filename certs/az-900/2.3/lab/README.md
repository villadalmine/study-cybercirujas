# AZ-900 2.3 lab: Describe Azure storage services

> **Warning: this lab does more than break a throwaway container.**
>
> - It creates real cloud resources that cost money until you delete them.
>
> Creates a real, billable Azure Storage account and resource group in your subscription. Use a sandbox or free-credit subscription and run `break_fix.sh cleanup` when you finish: until then it keeps costing money.

The lab is `break_fix.sh` (its header explains the faults and the verbs) and `lab.yaml`, which declares this warning under `safety:`. `teach lab up az-900 2.3` prints it and asks for confirmation before anything starts.
