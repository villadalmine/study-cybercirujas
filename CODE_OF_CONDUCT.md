# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. In short:

- Be respectful and welcoming, in every language this project speaks. Many
  contributors write in their second or third language; read generously.
- Criticise material and code, not people. A correction backed by an official
  source is a contribution, not an attack.
- No harassment, personal attacks, discriminatory language, or publishing
  others' private information.

**Scope:** the repository, its issues, pull requests and discussions, and any
space where someone represents the project.

**Reporting:** contact a maintainer listed in [docs/GOVERNANCE.md](docs/GOVERNANCE.md)
privately through their GitHub profile. Reports are handled confidentially.
Maintainers who do not follow this code may be removed from their role.

Enforcement follows the Contributor Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
